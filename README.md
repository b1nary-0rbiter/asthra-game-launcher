# asthra-game-launcher
A collection of small unity games developed for the technical showcase of asthra 2026. Each game is build and maintained by a different contributor.

# Games list

|------|---------|----------------|--------|

## Folder layout

```
games/
  game1/   <- one full Unity project
  game2/   <- another full Unity project
  game3/   <- another full Unity project
```

Each game folder has its own complete Unity project inside it. Nobody shares files across folders.

## How to add your game

1. Fork this repo
2. Create a new folder: `games/your-game-name/`
3. Put your Unity project inside it
4. Add your game to the table above
5. Open a Pull Request

Full details in [CONTRIBUTING.md](CONTRIBUTING.md).
