# Contributing

## Rules

- Use Unity 2022.3 (or close to it)
- Put your game in its own folder: `games/your-game-name/`
- Don't touch or edit other people's folders
- Always commit `.meta` files (Unity creates these automatically — just don't delete or ignore them)
- Don't commit the `Library`, `Temp`, `Obj`, or `Build` folders — the `.gitignore` already blocks these

## Steps to add your game

1. Fork this repo
2. Make a folder: `games/your-game-name/`
3. Copy your Unity project into that folder
4. Add a short `README.md` inside your folder saying:
   - What the game is
   - Your name or GitHub username
   - Controls (how to play)
5. Add your game to the table in the main `README.md`
6. Open a Pull Request

## Before you submit, check:

- [ ] My game only touches my own folder
- [ ] `.meta` files are included
- [ ] My folder has its own README
- [ ] I added my game to the main README table
- [ ] The project opens with no errors in Unity 2022.3
